# UIUC Course Homelander

A Chrome extension that helps University of Illinois Urbana-Champaign (UIUC) students automatically register for courses when spots become available.

## Features

- Automatically monitors course availability in real-time
- Instantly attempts to register when a spot opens up
- Simple start/stop interface
- Works with the UIUC Banner registration system
- Configurable monitoring interval

## Installation

1. Clone this repository or download the ZIP file
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the extension directory

## Usage

1. Navigate to the UIUC Banner registration system
2. Search for your desired course
3. Click the extension icon in your Chrome toolbar
4. Click "Start" to begin monitoring
5. The extension will automatically attempt to register when a spot becomes available
6. Click "Stop" to end the monitoring process

## Important Notes

- The extension requires you to be logged into the UIUC Banner system
- Keep the browser window open while monitoring
- The extension checks for availability every 10 seconds
- Make sure you have the necessary prerequisites and permissions to register for the course

## Permissions

This extension requires the following permissions:
- Access to the UIUC Banner registration system
- Ability to interact with the registration page
- Active tab access
